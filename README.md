# Credit Card Fraud Detection Using Anomaly Detection

Major Project | Department of CSE (Data Science), SSIPMT, Raipur

## Objective
To detect fraudulent credit card transactions using unsupervised anomaly detection models (Isolation Forest, Autoencoder and Local Outlier Factor), without depending on a large number of fraud labels.

## Dataset
ULB Credit Card Fraud Detection dataset (Kaggle)
https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud

- 284,807 transactions, 31 columns
- 492 frauds (0.173%), so the data is highly imbalanced
- The dataset file is not uploaded here because of its size. Please download it from the link above.
